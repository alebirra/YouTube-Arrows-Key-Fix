# YouTube Arrow Keys

Minimal Chrome extension that forces YouTube arrow keys to behave consistently:

- Left / Right: seek backward / forward 5 seconds
- Up / Down: increase / decrease volume by 5%

It has no popup, no background worker, no storage, and no extra permissions.

## Install

1. Open `chrome://extensions`.
2. Enable `Developer mode`.
3. Click `Load unpacked`.
4. Select this folder: `youtube-arrow-keys-extension`.
5. Reload any open YouTube tabs.
